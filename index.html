uCoz API - Документация

Выберите модуль для просмотра документации API

📰

Новости сайта

API для работы с модулем "Новости сайта" - получение, добавление, редактирование и удаление новостей, категорий и комментариев.
📋

Доска объявлений

API для работы с модулем "Доска объявлений" - управление объявлениями, категориями и комментариями.
📚

Каталог статей

API для работы с модулем "Каталог статей" - управление статьями, категориями и комментариями.
✍️

Блог

API для работы с модулем "Блог" - управление записями блога, категориями и комментариями.
📷

Фотоальбом

API для работы с модулем "Фотоальбом" - управление фотографиями, категориями и комментариями.
🎬

Видео

API для работы с модулем "Видео" - управление видео материалами, каналами, категориями и комментариями.
❓

FAQ

API для работы с модулем "FAQ" (Вопросы и ответы) - управление вопросами, ответами и категориями.
💬

Форум

API для работы с модулем "Форум" - управление форумами, темами и сообщениями.
🛒

Интернет-магазин

API для работы с модулем "Интернет-магазин" - управление товарами, корзиной, заказами, категориями и валютой.

Примечание: Все запросы к API требуют авторизации через Bearer токен. Для получения токена доступа необходимо зарегистрировать приложение на сайте uCoz. При использовании "Try it" укажите свой домен в поле "Server" и введите Bearer токен в поле "Authorize".
